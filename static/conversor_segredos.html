Montar o texto dos Secrets

Cole o conteúdo do arquivo JSON da conta de serviço e preencha o resto. O texto pronto aparece embaixo para você colar em Manage app → Settings → Secrets. Tudo acontece aqui no seu navegador: nada é enviado para lugar nenhum.

Pode colar o link inteiro da planilha: o sistema pega só o ID. É com esse NIP e essa senha que você vai entrar no SisEscala.
